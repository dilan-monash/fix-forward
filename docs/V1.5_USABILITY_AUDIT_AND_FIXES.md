# FixForward v1.5 — Usability audit and fixes

**Audit type:** expert heuristic review + scripted persona walkthrough + automated contract/logic tests.  
**Important:** this is **not** a substitute for observed usability sessions with real participants. No claim is made that 10–15 users completed this audit.

## Walkthrough personas used

1. Broken vacuum owner who only wants a repair place.
2. Kettle owner who noticed a burning smell.
3. User who does not know what “product recall” means.
4. User who knows the appliance category but not the model.
5. User who mistypes a known recall model by one character.
6. User who wants to compare a repair quote with replacement.
7. User who wants to recycle and does not want to share location.
8. User who allows browser location and wants nearest results.
9. User who cannot understand a safety question.
10. User who is not willing/able to inspect the appliance.
11. Keyboard-only user.
12. User on a slow/cold Render/Neon start.
13. User whose map/CDN fails.
14. User whose recall endpoint fails while safety UI is still available.
15. User whose service-location endpoint is slow/unavailable.

## Product decision still needed

The final Iteration 1 acceptance criteria must explicitly approve or reject:

- goal-first shortcuts;
- device geolocation;
- different safety depth by user goal;
- early-stop after Yes/Not sure;
- uncertain recycling contact-first continuation.

Do not silently treat this prototype as the final approved scope.
