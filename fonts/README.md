# Bundled fonts

FixForward serves its two typefaces from this folder so no font request leaves the website and no third party sees visitors.

| File | Typeface | Use | Licence |
|---|---|---|---|
| `baloo-2-latin.woff2` | Baloo 2 (variable weight, Latin subset) | Headings | SIL Open Font License 1.1, see `BALOO2-OFL.txt` |
| `nunito-latin.woff2` | Nunito (variable weight, Latin subset) | Body text, labels and buttons | SIL Open Font License 1.1, see `NUNITO-OFL.txt` |

Both files come from the Fontsource packages `@fontsource-variable/baloo-2` and `@fontsource-variable/nunito` (version 5.3.0). They are declared once in `brand.css`.
